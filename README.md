# ХлебМясо — сайт магазина

Сайт-каталог в фирменных цветах магазина: поиск, корзина и оформление заказа в WhatsApp.
Работает без сервера и без базы данных — просто откройте `index.html` в браузере.

---

## Файлы

```
хлеб мясо/
├── index.html          ← главная страница (открывать эту)
├── css/styles.css      ← оформление
├── js/config.js        ← ⚙️ НАСТРОЙКИ: телефон, WhatsApp, адрес, доставка
├── js/products.js      ← 🛒 КАТАЛОГ: категории и товары
├── js/app.js           ← логика (поиск, корзина, заказ) — трогать не нужно
└── assets/             ← логотип и фотографии магазина
```

---

## Фирменный стиль

Цвета сняты пипеткой с логотипа магазина:

| Цвет | Код | Где используется |
|---|---|---|
| Оранжевый | `#FFA000` | кнопки, акценты, активные разделы, плашки «хит» |
| Чёрный | `#111111` | шапка-полоса, галерея, подвал, текст |
| Белый | `#FFFFFF` | фон страницы и карточек |

Все цвета лежат переменными в самом верху `css/styles.css` (блок `:root`) — поменяете там одно значение, и оно применится по всему сайту.

Логотип (`assets/logo.png`) вырезан из их же карточки на Яндекс.Картах: круг с прозрачным фоном, поэтому нормально смотрится и на белом, и на чёрном. `assets/favicon.png` — иконка вкладки браузера.

## Фотографии

В `assets/` лежат 23 настоящие фотографии магазина с их карточки на Яндекс.Картах — витрины с мясом, пекарня, лаваши, орехи на развес, суджук, чак-чак в фирменной упаковке, вывеска ночью, интерьер.

Где они используются:

- **Шапка-баннер** — ночная вывеска (`sign-night.jpg`);
- **Плитки разделов** — по фотографии на раздел (у кого фото нет — фирменная оранжевая плитка со значком);
- **Карточки товаров** — 18 товаров уже с реальными фото, помечены плашкой «фото из магазина»;
- **Галерея «Как у нас в магазине»** — 12 снимков в самом низу.

### Добавить фото к товару

Положите файл в `assets/` и допишите в строку товара поле `img`:

```js
{ id:'m02', cat:'meat', name:'Баранина, корейка на кости', desc:'Для шашлыка',
  price:1050, unit:'кг', emoji:'🐑', badge:'', img:'assets/korejka.jpg', tags:'баранина корейка' },
```

Если `img` нет — карточка покажет эмодзи на светлой плашке. Это нормально, так и задумано: можно добавлять фото постепенно.

Размер лучше делать примерно 1000 px по длинной стороне, иначе сайт будет тяжёлым. Быстро уменьшить пачку фото на Маке:

```bash
sips -Z 1000 -s format jpeg -s formatOptions 50 фото.jpg --out assets/фото.jpg
```

## 1. Поменять номер WhatsApp и контакты

Откройте `js/config.js`:

```js
phone:      '+7 (932) 000-85-55',   // как показывать на сайте
phoneHref:  '+79320008555',         // куда звонить при нажатии
whatsapp:   '79320008555',          // ← СЮДА падают заказы. Без плюса и пробелов!
```

⚠️ В поле `whatsapp` номер пишется **без плюса, скобок и пробелов** — например `79320008555`.
Если заказы должны идти на другой номер (менеджеру) — меняется только эта строка.

Там же настраивается доставка:

```js
delivery: {
  minSum:   1000,   // минимальная сумма заказа на доставку
  freeFrom: 3000,   // от этой суммы доставка бесплатная
  price:    200,    // стоимость доставки, если сумма меньше
  zone:     'Доставляем по Дербенту и ближайшим посёлкам'
}
```

## 2. Добавить или изменить товар

Откройте `js/products.js`. Один товар — одна строка:

```js
{ id:'m15', cat:'meat', name:'Баранина, рёбра', desc:'Халяль, охлаждённая',
  price:750, unit:'кг', emoji:'🐑', badge:'новинка', tags:'баранина рёбра халяль' },
```

| Поле | Что это |
|---|---|
| `id` | уникальный код товара. **Не должен повторяться!** |
| `cat` | категория — из списка `CATEGORIES` в начале файла |
| `name` | название на карточке |
| `desc` | короткое описание |
| `price` | цена числом, без пробелов и знака ₽ |
| `unit` | `'кг'`, `'шт'`, `'уп'`, `'л'`. При `'кг'` товар добавляется шагом 0,5 кг |
| `emoji` | картинка-заглушка, если нет фото |
| `img` | путь к настоящему фото (необязательно) |
| `badge` | `'хит'`, `'новинка'`, `'акция'` или пусто `''` |
| `tags` | слова для поиска через пробел |

**Удалить товар** — удалите строку целиком. **Изменить цену** — поменяйте число в `price`.

### Новая категория

В начале `js/products.js`, в списке `CATEGORIES`:

```js
{ id: 'fish', name: 'Рыба и морепродукты', icon: '🐟', photo: 'assets/ryba.jpg' },
```

`photo` можно оставить пустым `''` — тогда плитка будет фирменная оранжевая. Дальше ставьте товарам `cat:'fish'`.

## 3. Как открыть сайт

**Посмотреть** — двойной клик по `index.html`.

**Проверить на телефоне** (Мак и телефон в одном Wi-Fi) — в Терминале из этой папки:

```bash
python3 -m http.server 8777
```

Узнайте IP Мака (Системные настройки → Wi-Fi → Подробнее) и наберите на телефоне `http://ВАШ_IP:8777`.

---

## 4. Выложить в интернет

Сайт статический — подойдёт любой бесплатный хостинг:

- **Netlify Drop** — [app.netlify.com/drop](https://app.netlify.com/drop): перетащить папку в окно браузера, через 20 секунд будет ссылка.
- **GitHub Pages** — залить папку в репозиторий и включить Pages.
- **Обычный хостинг (Timeweb, Beget)** — закинуть содержимое папки в `public_html` по FTP.
